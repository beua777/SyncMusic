# SyncMusic

삼성 뮤직처럼 생긴 **나만의 Windows 음악 플레이어**와, 같은 Wi-Fi에서 **갤럭시 폰(삼성 뮤직)과 자동으로 음악·재생목록을 맞추는 동반 앱**이에요.

- 디자인: One UI 스타일 (트랙·재생목록·앨범·아티스트·폴더 탭, 둥근 카드, 플로팅 미니 플레이어, 앨범 색이 배어 나오는 재생 화면, 라이트/다크, 곡마다 자기 커버)
- 디자인 꾸미기: 포인트 색, 재생 화면 위에서 내려오는 색(앨범 색·커버 흐리게·랜덤·무지개·무지개 단색·직접 고르기), 오디오 스펙트럼(커버 쪽: 막대·대칭·물결·원형, 화면 아래 전체를 따로), 무지개 속도, 화면 효과(눈·벚꽃·낙엽·비·별·반딧불·비눗방울·하트), 박자에 맞춰 커버가 커지거나 빛남
- 셔플·반복: 삼성 뮤직에서 볼 수 있는 규칙을 그대로 재현하고 테스트로 고정 ([docs/PLAN.md](docs/PLAN.md) 5장). 취향 셔플 · 가수·앨범 흩기 · 같은 가수 연달아 막기 · 곡마다 셔플 제외
- 소리: 크로스페이드 · 10밴드 이퀄라이저(프리셋 12가지) · 음량 평준화(ReplayGain, 없으면 직접 재서 EBU R128) · 재생 속도(음 높이 유지) · A-B 구간 반복 · 재생/멈춤 페이드 · 무음 건너뛰기 · 곡마다 음량 · 출력 장치마다 음량 기억 · 음질 정보
- 재생목록: 색·아이콘 · 재생목록마다 셔플·반복 방식 · 변경 이력(되돌리기) · 중복 곡 정리 · 지운 재생목록 되살리기
- 검색: 자연어("최근 추가한 일본 노래 10곡") · 고급 필터(조건 조합·저장) · 오타 허용 · 일본어 발음(요아소비 = YOASOBI = ヨアソビ) · 가사로 찾기 · 최근 검색 · 키보드로 목록 이동
- 가사: 시간 맞춰 편집 · 온라인에서 찾기(LRCLIB) · 번역 나란히(.lrc 번역 줄, 없으면 자동 번역) · 크기·정렬·노래방 칠하기
  - 온라인 찾기는 유튜브에서 받은 곡 제목(`가수『제목』MV`, `【올린 사람】 가수 - 제목 Cover`, `번역 제목 (原題)` 등)에서 제목·가수 후보를 뽑아 여러 번 찾고, 결과마다 제목·가수·길이가 얼마나 맞는지 점수(잘 맞음 · 비슷함 · 다를 수 있음)를 매겨요. 이름은 가나·한글·로마자 소리와 한자 읽는 법으로도 비교하고, 제목·가수를 고쳐 다시 찾을 수 있어요
  - 제목이 한국어뿐인 곡(번역 제목만 단 한국어 커버)은 제목을 일본어로 번역해 원제로도 찾아요(가사 자동 번역과 같은 구글 번역, 자동 번역을 끄면 안 함). 붙여 쓴 제목(`제목가수`)은 가수 이름만으로도 찾아 띄어쓰기 없이 비교해요
- 곡 정보 · 곡 안 북마크 · 커버 바꾸기(앱에만 저장) · 이 곡 화면 테마 · 화면 배치 편집 · 작은 창(항상 위) · 단축키 바꾸기
- 들은 기록 통계: 주간·월간·연간 리포트 · 시간대 · 아티스트 비율 · 오래 안 들은 곡 · 최근 추가 · 취향 추천 · 취향 변화 · 청취 목표 · 연말 결산 · CSV/JSON 내보내기
- 도구: 라이브러리 점검(없는 파일·태그·중복 곡 휴지통 정리·변경 기록) · 오류 기록 · 설정 백업/복원 · 새 버전 알림·업데이트 · 수면 타이머 뒤 앱 종료·PC 절전/끄기 · 재생 상태 복구 · 저사양 모드(켜기·배터리일 때만)
- 동기화: 삼성 뮤직 재생목록을 **순서 그대로** PC로 가져오고, 양쪽에서 고쳐도 3-way 병합으로 순서 보존. 원하면 동기화 전에 바뀔 내용을 보고 허락
- 이어듣기: 폰에서 듣던 곡·위치·섞인 대기열을 PC에서 그대로 이어서 재생

자세한 설계는 [docs/PLAN.md](docs/PLAN.md)에 있어요.

## 1. PC 플레이어 실행

필요한 것: Node.js 22.12 이상 (이 PC에는 24가 설치돼 있어요), Microsoft Edge

1. `pc\SyncMusic.cmd`를 더블클릭하세요. 처음 실행하면 필요한 파일을 설치하고, 주소창 없는 앱 창이 열려요.
   - 터미널에서는 `cd pc` 후 `npm install`, `node launch.js`
2. 설정(⋮ → 설정)에서 **음악 폴더**를 확인하세요. 기본은 `내 음악`(`C:\Users\<이름>\Music`)이에요.
3. 원하면 설정 → Windows에서
   - **바탕화면 바로가기 만들기**
   - **로그인할 때 백그라운드로 실행** (창을 안 열어도 폰 동기화)
4. 창을 닫아도 서버는 동기화를 위해 계속 돌아요. 끄려면 설정 → **SyncMusic 완전히 종료**.

데이터(라이브러리·재생목록·재생 상태)는 `%LOCALAPPDATA%\SyncMusic`에 저장돼요. 폰에서 받은 곡은 첫 번째 음악 폴더의 `From Phone` 폴더에 들어가요.

### 디자인 꾸미기

설정 → 화면 → **디자인 꾸미기**, 또는 재생 화면의 팔레트 버튼(디자인 탭)에서 바꿔요. 고르는 즉시 바뀌고 저장돼요.

| 항목 | 고를 수 있는 것 |
|------|----------------|
| 포인트 색 | 기본 파랑 · 8가지 색 · 직접 고르기 (다크 테마에서는 읽히게 밝기를 자동으로 맞춤) |
| 재생 화면 배경 | 앨범 색 · 커버 흐리게(커버 그림을 크게 흐려서 깔기) · 랜덤(곡마다, 한 번 더 누르면 지금 바꿈) · 무지개(여러 색이 천천히 흐름) · 무지개 단색(한 색이 무지개 순서로 서서히 바뀜) · 직접 고르기 · 끄기, 진하기 |
| 오디오 스펙트럼 | 커버 쪽(막대 · 대칭 · 물결 · 원형 · 끄기 — 원형은 커버가 LP처럼 돎), 화면 아래 전체(막대 · 대칭 · 물결 · 끄기, 커버 쪽과 같이 켤 수 있음), 색(앨범 색 · 무지개 · 무지개 단색 · 랜덤 · 포인트 색 · 직접 고르기), 미니 플레이어에도 보이기 |
| 무지개 | 속도(한 바퀴 약 4초 ~ 96초), 위쪽 배경과 스펙트럼의 색(같은 색 · 조금 다르게 · 반대 색) |
| 화면 효과 | 눈 · 벚꽃 · 낙엽 · 비 · 별(가끔 별똥별) · 반딧불 · 비눗방울 · 하트, 양, 색(기본 · 무지개 · 포인트 색), 보일 곳(재생 화면에서만 · 앱 전체), 음악에 반응(박자에 맞춰 빨라지고 밝아짐) |
| 박자에 맞춰 커버가 | 끄기 · 커짐 · 뒤에서 빛남 · 둘 다 (음악의 낮은음에 맞춰) |
| 움직임 부드러움 | 절약(초당 15번) · 보통(30번, 기본) · 부드럽게(60번) — 스펙트럼·화면 효과를 그리는 횟수. 낮출수록 CPU를 덜 써요 |
| 화면 배치 | 커버 크기 · 옆 패널 위치(오른쪽·왼쪽) · 재생 출처·음질 표시·보조 버튼 보이기 · 미니 플레이어 버튼 · 위쪽 탭 순서와 보이기 |

스펙트럼은 음량과 상관없이 같은 높이로 보여요. 배경과 스펙트럼을 둘 다 무지개 단색으로 하면 같은 색으로 함께 바뀌어요. 커버는 곡 파일에 든 그림을 곡마다 따로 쓰고, 그림이 없으면 같은 폴더의 `cover.jpg` 등을 써요. 곡 메뉴의 **이 곡 화면 테마**로 곡마다 배경·스펙트럼 색·효과를 따로 정할 수 있어요.

**CPU 아끼기**: 재생 화면이 닫혀 있으면 그 안의 애니메이션은 멈추고, 재생 화면이 열려 있으면 뒤의 목록은 그리지 않아요. 창이 뒤에 있으면 스펙트럼을 초당 15번만 그리고, 멈춰 있으면 아무것도 그리지 않아요. 무지개 배경은 매 프레임이 아니라 0.1~0.5초마다만 색을 바꿔요. 이퀄라이저를 끄면 필터를 아예 거치지 않아요. 그래도 무거우면 **움직임 부드러움 → 절약**으로 바꾸거나 저사양 모드를 켜세요.

**저사양 모드** (설정 → 성능, 디자인 탭의 움직임 부드러움, ⋮ 메뉴): 끄기 · 켜기 · 배터리일 때만(노트북에서 전원을 뽑으면 켜지고 꽂으면 꺼짐). 켜면 화면 효과 · 박자 반응 · 화면 아래 스펙트럼 · 미니 스펙트럼 · 움직이는 배경(무지개·무지개 단색·커버 흐리게는 앨범 색으로) · 커버 회전을 쉬고, 스펙트럼은 1초에 15번만 그려요. 음악을 듣는 동안에는 곡 소리 재기(음량 평준화)도 쉬어요. 디자인에서 고른 값은 바꾸지 않아서, 끄면 그대로 돌아와요. 별 효과·박자 반응까지 켠 디자인으로 재 보니 재생 화면을 열고 들을 때 CPU 한 코어의 약 30% → 약 12%, 재생 화면을 닫고 들을 때 약 12~16% → 약 5%였어요.

### Windows 방화벽

폰이 PC에 접속하려면 Node.js가 들어오는 연결을 받을 수 있어야 해요 (TCP 47811, UDP 47812).

- 이 PC는 지금 Wi-Fi가 **공용 네트워크**이고, Node.js가 공용 네트워크에서 이미 허용돼 있어요.
- Wi-Fi를 **개인 네트워크**로 바꾸면 처음 실행 때 방화벽 창이 뜰 수 있어요. 그때 개인 네트워크를 허용하세요.

## 2. 폰 동반 앱 설치

APK는 저장소 [beua777/SyncMusic](https://github.com/beua777/SyncMusic)의 GitHub Actions(**Android 동반 앱** 워크플로)가 만들어요. 코드를 올릴 때마다 Kotlin 단위 테스트를 돌리고 APK를 빌드해요.

- 받는 곳: 저장소 → Actions → 가장 최근 **Android 동반 앱** 실행 → Artifacts의 `syncmusic-companion-apk`
- 이 PC에는 내려받아 둔 파일이 `dist\SyncMusic-companion-0.1.0.apk`에 있어요 (git에는 안 올라감)

폰에 설치하기:
1. APK를 폰으로 옮겨요 (USB 복사, Quick Share, 구글 드라이브 등).
2. 내 파일 앱에서 APK를 눌러요. "출처를 알 수 없는 앱 설치"를 허용해요.
3. Play 프로텍트가 알 수 없는 앱이라고 경고하면 "무시하고 설치"를 눌러요. 개인용이라 디버그 키로 서명돼 있어요.

**업데이트**: 0.2.0부터는 늘 같은 서명 키로 빌드돼서, 새 APK를 그냥 덮어 설치하면 돼요. 0.1.0은 임시 키로 서명돼 있었어요. 그래서 0.1.0에서 0.2.0으로 올릴 때만 한 번 지우고 설치한 뒤 PC와 다시 연결해야 해요.

서명 키 원본은 이 PC의 `%USERPROFILE%\.syncmusic\signing`에 있고, 저장소에는 Actions 비밀값(`SYNCMUSIC_KEYSTORE_B64`, `SYNCMUSIC_KEYSTORE_PASSWORD`)으로만 들어 있어요. 지우지 마세요. 잃어버리면 다음 업데이트 때 다시 지우고 설치해야 해요.

직접 빌드하려면 Android Studio에서 `android` 폴더를 열고 ▶ 실행하세요 (Gradle 8.9, JDK 17). 명령줄로는 `gradle assembleDebug`. 같은 키로 서명하려면 `SYNCMUSIC_KEYSTORE`(키 파일 경로)와 `SYNCMUSIC_KEYSTORE_PASSWORD` 환경 변수를 주면 돼요.

### 폰 설정 (처음 한 번)

1. **삼성 뮤직** → ⋮ → 설정 → **플레이리스트 관리**
   - **모든 플레이리스트 자동 백업**을 켜요.
   - **폴더 선택**에서 저장 폴더를 확인해요 (예: `Music/Playlists`).
2. **SyncMusic 동반 앱**에서
   - 음악 파일·알림 권한을 허용해요.
   - **폴더 선택** → 1번과 같은 폴더를 골라요.
   - **PC 연결** → PC 설정의 **새 휴대폰 연결**에 보이는 6자리 코드를 입력해요.
   - (선택) **이어듣기 허용**에서 SyncMusic을 켜면 폰에서 듣던 곡을 PC로 보낼 수 있어요.
3. 갤럭시는 오래 안 쓴 앱의 백그라운드 작업을 멈출 수 있어요. 자동 동기화가 늦으면 설정 → 배터리 → 백그라운드 사용 제한에서 SyncMusic을 절전 예외로 두세요.

그다음부터는 같은 Wi-Fi에 있으면 약 15분마다, 그리고 앱을 열 때마다 동기화돼요.

## 3. 동기화가 하는 일

| 방향 | 내용 |
|------|------|
| 폰 → PC 음악 | 폰 재생목록(삼성 뮤직 백업)에 든 곡만 PC `From Phone` 폴더로 복사 (기본). PC 설정에서 기기별로 "폰의 모든 음악"이나 "가져오지 않음"을 고를 수 있음 |
| PC → 폰 음악 | 동기화하는 재생목록에 든 곡(기본) 또는 전체를 폰 `Music/SyncMusic`으로. 삼성 뮤직이 바로 인식 |
| 폰 → PC 재생목록 | 삼성 뮤직 자동 백업 파일을 읽어 **순서 그대로** |
| PC → 폰 재생목록 | 백업 폴더에 그 폰이 쓰는 형식(`.smpl` 또는 `.m3u`)으로 저장 → 삼성 뮤직에서 **플레이리스트 가져오기**를 한 번 누르면 반영 |
| 양쪽에서 수정 | 3-way 병합: 최근에 바꾼 쪽 순서 + 반대쪽에서 넣고 뺀 곡 반영 |
| 이어듣기 | 폰에서 듣던 곡·위치·대기열 순서·셔플/반복 → PC 화면의 **PC에서 이어 듣기** |
| 동기화 전에 확인 (기기별, 선택) | 폰이 연결되면 바로 바꾸지 않고, PC 설정에 받을 곡·보낼 곡·바뀔 재생목록을 보여 줘요. **허락하고 동기화**를 누르면 30분 안에 폰이 다시 연결될 때 한 번 동기화해요 |

안전을 위해 **음악 파일 삭제는 동기화하지 않아요.** 한쪽에서 지워도 다른 쪽에는 남아요.

### 알아 둘 한계

- 삼성 뮤직은 다른 앱이 재생목록에 직접 쓰는 기능을 주지 않아요. 그래서 PC에서 바꾼 재생목록은 삼성 뮤직에서 **가져오기**를 눌러야 반영돼요. 바뀌면 폰에 알림이 떠요.
- 삼성 뮤직의 셔플 알고리즘은 공개돼 있지 않아요. 공식 도움말과 화면에서 볼 수 있는 규칙(한 바퀴 동안 중복 없음, 셔플 켜도 지금 곡 유지, 반복 3단계, 이전 버튼 두 번 등)을 재현했어요.
- 폰 앱은 GitHub Actions에서 빌드와 단위 테스트를 통과했지만, 실제 갤럭시에서는 아직 시험하지 않았어요. 아래 체크리스트로 확인이 필요해요.
